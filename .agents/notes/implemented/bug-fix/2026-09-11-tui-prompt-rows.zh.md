# Agent Note: 把模态提示渲染为输入框上方的普通行

Status: implemented

[English](2026-09-11-tui-prompt-rows.md) | 中文

## 问题

`/model`、`/resume`、审批和用户提问都通过同一个 `PromptPanel` 以 overlay 形式呈现：一行加粗标题、一行空行，然后是选择器或输入控件的主体。面板没有边框，宽度最多 76 列，而 pi-tui 渲染器只在 overlay 声明的列范围内合成内容，其余部分保留转录已打印的内容。因此转录文字会与提示出现在同一批行上、分布在它两侧，并被读作它的一部分。在用户报告的 `/model` 场景中，`/help` 通知发生了折行，续行（`<objective>|pause|resume]`）正好贴在面板空行旁边，而 `/goal`、`/permission`、`/plan` 的前几列又与面板自身文字拼在一起：`SSelect a model`、`S→ deepseek-…`、`E  deepseek-…`。结果既不像输出，也不像对话框。

## 决策

`PromptPanel` 以普通输出呈现：一行标题、一行空行，然后是主体；像转录行一样左对齐，并使用完整视口宽度。每一行都填充到 overlay 覆盖的宽度，因此面板占据的每整行都只属于面板，转录不会从旁边透出。

选择器的 `SelectList` 以 `minPrimaryColumnWidth: 1` 与 `maxPrimaryColumnWidth: Number.MAX_SAFE_INTEGER` 构建，让值列按最宽标签增长。组件默认把该列限制在 32 列并在其中截断值，于是每个完整的 `provider/model` 路由都会从中间被切断；改由内容决定列宽后，标签能完整显示，而在面板容不下标签与描述两者时，组件会先舍弃描述而不是截断值。

`showPrompt` 让 overlay 占满终端宽度，并以 `anchor: 'bottom-center'` 加上底部 margin（布局固定区：输入框三行加页脚两行）定位。于是备用屏幕布局中面板恰好位于输入框正上方、也就是转录结束的位置，读起来就是转录接下来的几行。内联布局没有固定页脚位置，因此仍保持居中锚点。

`promptPanelRows(rows)` 负责高度预算——最多 18 行、不超过可用行数减二、始终保留一行主体——`choose` 依据该预算决定可见列表条数（列表需要滚动时为 `SelectList` 的滚动提示预留一行主体），因此在矮终端上选择器会在面板内部滚动，而不会压到输入框。

## 备选方案

**带边框、居中的浮窗。** 用 `┌ title ─┐` / `└─┘` 横线把对话框与转录分开，这是最初的实现。它败在观感上：本界面其余行都是普通文本，方框引入了第二套视觉语言，而且整块是浮在转录之上而不是延续它。

**把列表写进转录。** 像 `/help` 那样打印编号行、把下一次提交解释为选择，可以让提示成为 scrollback 的一部分。它需要新增 pending-answer 状态来分流 `submit`、处理无效输入与取消，并在之后追加一行记录答案；列表还可能被滚出视野，在内联布局下更会永久留在 scrollback。

**在提示后面压暗或填充背景。** overlay 渲染器没有压暗层或背景填充，主题也只有属性与前景色；把覆盖到的整行交给面板即可获得同样的分隔效果，无需引入每个终端都必须渲染的背景色。

**保持居中而不贴到输入框上方。** 居中不需要了解布局，改动最小，但居中的整块读起来更像浮窗，而不是转录接下来的行。

**缩短标签而不是加宽值列。** 当部署只注册一个 provider 时去掉 provider 前缀——页脚的模型标签已经这么做——可以让大多数 id 放进组件默认的列宽。它没有被采用，因为选择器设置的正是标签所显示的路由，而注册多个 provider 的部署仍然需要完整的 `provider/model`；让列宽随内容增长可以在任何 provider 数量下都如实显示标签，并在空间不足时先舍弃描述。

## 后果

提示现在独占输入框上方的整行：转录被这些行遮住并在其上方继续，选择器每一行都是普通填充行。面板在外围占用两行（标题与空行），因此主体预算等于 `promptPanelRows` 减去这两行；一旦外围或固定页脚变化，应用就必须重新计算该预算。`PROMPT_PANEL_CHROME_ROWS` 与底部 margin 是两个独立常量，因为固定行属于应用布局而非面板。

`tests/transcript.spec.ts` 固定了标题、空行、主体位置、多种视口下每一行的精确宽度、标题截断以及行预算。`tests/tui-app.spec.ts` 读取合成后的备用屏幕画面，断言选择器所在行不含转录文字、紧贴输入框上边框、较长的路由与其描述都完整保留，并且超过预算的列表在面板内部滚动。
